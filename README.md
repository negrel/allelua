# 🙏 `allelua` - Lua runtime blessed by programming gods.

`allelua` is a Lua runtime that aims to be secure, fast and provide a great
developer experience. It's written in C11 with 0 external dependencies.

## Contributing

[issue](https://github.com/negrel/allelua/issues) or make a
